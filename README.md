# [StallerBike Rental] 🚲

Web-App für einen Fahrradverleih mit geführten Touren. Fahrräder lassen sich Touren und Gästen zuweisen, wobei das System sicherstellt, dass kein Rad gleichzeitig in mehreren Touren eingeplant ist.

> **Status:** in Entwicklung, für einen realen Fahrradverleih
>
> Geplant
Statistiken, z. B. Auslastung der Räder und Touren
Wartungsverwaltung für den Fahrradbestand


## Tech-Stack

Flutter (Web) · Python · FastAPI · SQLModel / SQLAlchemy · SQLite · REST
